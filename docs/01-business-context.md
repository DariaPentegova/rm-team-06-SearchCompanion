# Проект «ПоПути»

Приложение для поиска попутчиков на междугородние поездки.

## 1. Цель проекта и KPI

### Цель проекта

Разработать MVP приложения «ПоПути», которое связывает водителей, совершающих междугородние поездки на личном автомобиле, с пассажирами, готовыми разделить расходы на бензин.

### KPI проекта

| Показатель | Целевое значение |
|---|---|
| Количество забронированных мест | 10 000 в месяц через 6 месяцев после запуска |
| Доля отменённых поездок | Не более 5% |

## 2. Проблема

### Основные проблемы пользователей

1. Пассажиры ищут попутчиков через социальные сети.
2. Водители отменяют поездки в последний момент.
3. Пассажиры не приходят на поездки.
4. Незнакомым людям сложно доверять друг другу.

## 3. Заказчик и его ожидания

### Заказчик

Стартап «ПоПути».

### Ожидания заказчика

1. Создать сервис для поиска попутчиков на междугородние поездки.
2. Обеспечить возможность компенсации расходов водителя на бензин.
3. Реализовать подтверждение номера телефона пользователей.
4. Предусмотреть правила поздней отмены бронирования.
5. Получать комиссию 10% с пассажира.
6. Достичь 10 000 забронированных мест в месяц через 6 месяцев после запуска.
7. Обеспечить долю отменённых поездок не более 5%.

## 4. Заинтересованные стороны (стейкхолдеры)

| Стейкхолдер | Интересы и ожидания |
|---|---|
| Заказчик (стартап «ПоПути») | Запуск сервиса, достижение KPI, получение комиссии 10% с пассажира |
| Водитель | Поиск пассажиров, компенсация расходов на бензин |
| Пассажир | Поиск поездок, бронирование мест, возможность отмены бронирования и возврата денег |
| Модератор | Модерация сервиса |
| Платёжный сервис | Обработка оплаты бронирований и возврата денежных средств |
| SMS-шлюз | Подтверждение номера телефона пользователей |
| Картографический сервис | Определение расстояния маршрута |

## 5. Бизнес-правила

| ID | Бизнес-правило |
|---|---|
| BR-01 | Сервис предназначен для совместных поездок на личном автомобиле, а не для оказания услуг такси. |
| BR-02 | Водитель не должен зарабатывать на поездке, а может только компенсировать расходы на бензин. |
| BR-03 | Направления поездок ограничены расстоянием до 500 км вокруг двух крупных городов. |
| BR-04 | Сервис взимает комиссию 10% с пассажира. |
| BR-05 | Номер телефона пользователя должен быть подтверждён. |
| BR-06 | Один пользователь может выступать как в роли водителя, так и в роли пассажира. |
| BR-07 | Пассажир может забронировать место в поездке при наличии свободных мест. |
| BR-08 | Бронирование места осуществляется с оплатой внутри приложения. |
| BR-09 | Водитель может отменить поездку с возвратом денег пассажирам. |
| BR-10 | Пассажир может отменить бронирование с возвратом денежных средств. |
| BR-11 | За позднюю отмену бронирования должно быть предусмотрено наказание. Конкретные условия требуют уточнения у заказчика. |
| BR-12 | После поездки пользователи могут оставлять отзывы и оценки. |
