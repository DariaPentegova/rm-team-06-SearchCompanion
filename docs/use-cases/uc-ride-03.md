## UC-RIDE-03. Бронирование поездки

**ID:** UC-RIDE-03

**Название:** Бронирование поездки

### Действующие лица

- Основное: пассажир.
- Другие действующие лица:
  - водитель;
  - вспомогательный картографический сервис;
  - платёжные сервисы.

### Предусловие

- У пассажира подтверждён номер телефона.
- Есть опубликованные поездки.

### Основной сценарий

1. Пассажиру виден список поездок.
2. Пассажир выбирает параметры фильтрации.
3. Пассажиру отображается список подходящих поездок.
4. Выбрав подходящую поездку, пассажир нажимает «Забронировать поездку».
5. Пассажиру отображается окно с подтверждением поездки, где система предупреждает, что на следующей странице нужно будет оплатить комиссию 10%.
6. Пассажир оплачивает комиссию через сторонний платёжный сервис.

### Альтернативный сценарий

- **2а.** Если нет ни одной подходящей поездки, то пассажир видит страницу «Ничего не найдено. Попробуйте изменить фильтр».

### Исключительный сценарий

- **4а.** Если все места в поездке уже забронированы, то отображается окно с ошибкой и просьбой выбрать другую поездку.
