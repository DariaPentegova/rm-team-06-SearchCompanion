## UC-RIDE-05. Отмена бронирования

**ID:** UC-RIDE-05

**Название:** Отмена бронирования

### Действующие лица

- Основное: пассажир.
- Другое действующее лицо: водитель.

### Предусловие

Поездка забронирована.

### Основной сценарий

1. Пассажир открывает карточку поездки.
2. Пассажир нажимает кнопку «Отменить бронирование».
3. Пассажир подтверждает отмену поездки.
4. Водителю приходит уведомление об отмене бронирования пассажиром.

### Альтернативный сценарий

- **3а.** Во всплывающем окне прописывается наказание в виде понижения рейтинга.

### Исключительный сценарий

- **3а.** Если подтверждение отмены поездки не прошло, то осуществляется возврат на пункт 2.
