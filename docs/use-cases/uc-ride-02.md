## UC-RIDE-02. Отменить поездку

**ID:** UC-RIDE-02

**Название:** Отменить поездку

### Действующие лица

- Основное: водитель.
- Вспомогательное: платёжный сервис.
- Вторичные: пассажиры.

### Предусловие

- Поездка опубликована.
- Есть подтверждённые бронирования.

### Основной сценарий

1. Водитель открывает вкладку «Мои поездки», флажок «Активные поездки».
2. Водитель нажимает «Отменить поездку» на карточке поездки.
3. Появляется окно подтверждения отмены.
4. Водитель подтверждает отмену.
5. Пассажиру возвращаются деньги на счёт.
6. Пассажиру приходит уведомление об отмене поездки.

### Альтернативный сценарий

- **3а.** Во всплывающем окне прописывается наказание в виде понижения рейтинга, если водитель отменяет поездку меньше чем за два часа до времени отправления.

### Исключительный сценарий

- **5а.** Если возврат денег пассажиру не прошёл, то осуществляется вторая попытка транзакции.
