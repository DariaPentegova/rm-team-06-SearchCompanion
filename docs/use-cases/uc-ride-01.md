## UC-RIDE-01

### 1. ID

UC-RIDE-01

### 2. Название

Опубликовать поездку.

### 3. Действующие лица

Основное действующее лицо: водитель.

Вспомогательное действующее лицо: картографический сервис (расстояние маршрута).

### 4. Предусловие

Водитель зарегистрирован; данные автомобиля указаны.

### 5. Постусловие

**При успехе:** поездка опубликована и доступна пассажирам.

**При неуспехе:** поездка не опубликована.

### 6. Сценарии

#### Основной сценарий

1. Водитель нажимает «Добавить поездку».
2. Водитель заполняет карточку поездки: дата, время, точка сбора, пункт назначения, пункт отправления (город), количество свободных мест.
3. Система рассчитывает поездку.
4. Водитель нажимает «Опубликовать поездку».

#### Альтернативный сценарий

**2а. Водитель исправляет данные поездки перед публикацией**

1. После заполнения карточки водитель изменяет дату, время, маршрут или количество свободных мест.
2. Система использует обновлённые данные.
3. Выполнение продолжается с шага 3 основного сценария.
   
#### Исключительные сценарии

**1а. Телефон водителя не подтверждён**

1. Водителю недоступна кнопка «Добавить поездку».
2. Поездка не публикуется.

**3а. Цена места выше компенсации расходов**

1. Водитель редактирует стоимость.
2. Выполнение возвращается к шагу 3 основного сценария.
