### Глоссарий

- Водитель - пользователь, который размещает поездку для поиска попутчиков с целью разделить расходы на топливо.
- Пассажир - пользователь, который ищет поездку, чтобы быстро и недорого добраться до пункта назначения.
- Пункт отправления - город, из которого водитель начинает поездку.
- Пункт назначения - город, в который едет водитель.
- Маршрут - путь следования водителя из пункта отправления в пункт назначения.
- Поездка - определенный маршрут с установленным временем и датой.
- Расстояние маршрута - протяженность маршрута в км.
- Модератор - пользователь, который модерирует поездки.
- Время отправления - запланир время начала поездки, когда водитель выезжает из дома.
- Дата поездки - календарная дата, на которую запланирована поездка.
- Карточка поездки - элемент интерфейса приложения, содержащий основные сведения: дату, время, кол-во свободных мест, стоимость и информацию об автомобиле.
